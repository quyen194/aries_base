# Database Examples

## Running Examples

```bash
./aries_base_example_database_basic
./aries_base_example_database_prepare
./aries_base_example_database_transaction
./aries_base_example_database_advanced
./aries_base_example_database_multi_db
```

## What Each Example Shows

- **basic** - Connect and execute queries
- **prepare** - Use prepared statements safely
- **transaction** - ACID transaction management
- **advanced** - Complex real-world scenarios
- **multi_db** - Same code works with different databases
